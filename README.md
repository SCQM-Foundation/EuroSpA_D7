# EuroSpA_D7

This repository contains R code used to perform the simulations and analyses of registry data in connection with the EuroSpA RCN study on "Impact of discontinuation definitions on comparative treatment retention: evidence from simulations and spondyloarthritis registry data".

Before running the simulation, please adapt all file paths specified in the scripts to your local directory structure.

The registry-data analysis code is provided for transparency but cannot be executed without access to the underlying registry data, which are not publicly available.
